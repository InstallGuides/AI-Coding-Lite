# Example research note

Use `1-research/` to capture what you learned *before* deciding something: options you compared, links, trade-offs. It's where a decision in `2-decisions/` gets its evidence.

**Example.** "Which language for the first example feature? Python reads almost like plain English and is forgiving for beginners, and uv runs a Python file with one command, so the example uses Python. Node, Ruby, Java and Rust are one `rewrite-in-language` skill away." This led to `2-decisions/ADR-001-example-decision.md`.
