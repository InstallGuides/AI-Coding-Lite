# PB-002: Run the example

**Status:** in use

This playbook is a procedure you repeat, which operations teams call a runbook. (Most playbooks are a one-time plan and task list for building a spec. See `PB-001`.) This one runs the hello example.

1. Open a terminal in this folder.
2. Type: `uv run source/hello.py`
3. If the terminal says `command not found: uv`, uv isn't installed yet. [Install uv](https://mac.install.guide/python/install-uv), then try again.
4. You should see: `Hello from your AI-Coding-Lite!`

To run it in another language, use the `rewrite-in-language` skill, or just ask your assistant.
